# shearidem

Shear encode/decode helpers for idem payloads in pipelines.

**Site:** https://theworker02.github.io/shearidem/

## Install / run

```bash
git clone https://github.com/theworker02/shearidem.git
cd shearidem
node src/cli.js
node --test
```
